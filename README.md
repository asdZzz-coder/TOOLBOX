# 工具盤點

管理與盤點工具的 Windows 小程式，以「物料整理」為基礎改寫。每項工具會記下這些資料：

- 名稱、分類、規格 / 型號、在庫數量、單位、備註
- **購入日期**
- **最後盤點日期**

報廢時會記下**報廢日期與原因**。

## 功能

### 工具與分類
- 左側是分類：全部工具、自訂分類、未分類、已報廢。分類可以新增、重新命名、刪除；刪除分類時，裡面的工具會移到「未分類」。
- 清單第二行顯示規格和購入日期，例如「18V · 2026/03/15 購入」。全部報廢的工具改顯示報廢日期與原因。
- 可以搜尋名稱、規格、單位、備註。
- 預設單位有支、把、個、組、套、台……，可以自己管理，也可以直接輸入清單以外的單位。

### 動作
選取工具後按下面的按鈕。每個動作都會改在庫數量，並留下一筆紀錄。

- **購入**：填數量、購入日期，說明可選填（例如在哪裡買的、價格）。
  - 工具的「購入日期」記的是第一次買進來的日期。
  - 新增工具時也可以直接填購入日期。
- **報廢**：填數量、報廢日期，並且一定要寫原因，例如壞掉、遺失、老舊汰換、無法維修；最近用過的原因可以一鍵帶入。
  - 一項工具全部報廢（在庫 0、也沒有借出）時，會移到左側的「已報廢」。
  - 舊的資料仍然保留可查。
- **借出**：一定要寫借給誰，日期預設今天。
- **歸還**：可以分次還。

### 盤點
1. 在左側選好範圍（全部工具或某個分類），按上方的「盤點」。
2. 填盤點日期。
3. 逐項在「實點」欄填上架上實際點到的數量。
   - 按 Enter 或 ↓ 跳到下一項。
   - 空白的表示還沒點，完成盤點時不會更動。
   - 借出中的工具不用點，畫面上會另外標示。
4. 每列會即時顯示「相符 / 多 N / 少 N」。可以按「未點的照帳面」把還沒點的都當作相符。
5. 按「完成盤點」：
   - 每項有點到的工具都會記下盤點日期。
   - 數量不符的，在庫會改成實點數量，並留下一筆盤點紀錄（帳面多少、實點多少）。

### 紀錄
- 「紀錄」視窗分兩頁：
  - **借出中**：可以直接按歸還。
  - **全部紀錄**：可以依動作篩選，並搜尋工具、原因、借用人。
- 購入、報廢、盤點的紀錄只顯示日期；借出、歸還的紀錄連時間一起顯示。

### Excel
- 匯出時，第一個工作表「工具」的欄位依序是：名稱、分類、規格、數量、單位、購入日期、最後盤點、備註。
  後面另外有「借出中」「已報廢」兩欄，只供查看。
- 另外附上「紀錄」和「借出中」兩個工作表。
- 匯入時只讀第一個工作表。
  - 名稱和規格相同的工具會更新資料。
  - 日期可以是 Excel 日期，也可以是文字，例如 `2026/10/8`、`115/10/8`。

### 日期輸入
這些寫法都可以：

- `2026/10/8`、`2026-10-08`、`20261008`
- 民國年：`115/10/8`
- `2026年10月8日`
- 只打 `10/8` 時當作今年

不能填未來的日期。

### 其他
- 支援淺色、深色、跟隨系統三種主題。
- 線上更新：開啟程式時會檢查 GitHub Releases，有新版會詢問是否更新。
- 資料存在 `%AppData%\ToolboxKeeper\toolbox.json`，是一般的 JSON 檔，可以直接備份。

## 安裝

1. 到 [Releases](https://github.com/asdZzz-coder/TOOLBOX/releases) 下載 `ToolboxKeeper-ClickOnce.zip`。
2. 解壓縮整個 zip。
3. 執行「安裝.cmd」。

已安裝的電腦開啟程式時，會自動檢查新版並詢問是否更新。

## 發佈新版

推送 `v*` 標籤（例如 `v1.0.1`）後，GitHub Actions 會跑測試、用 ClickOnce 打包，並建立 Release：

```bash
git tag v1.0.1
git push origin v1.0.1
```

## 開發

需要 .NET 10 SDK。

```bash
dotnet test toolbox.Tests/toolbox.Tests.csproj
dotnet run --project toolbox
```

測試時可以設定環境變數 `TOOLBOXKEEPER_DATA_DIR` 改用別的資料夾，就不會動到正式資料。
